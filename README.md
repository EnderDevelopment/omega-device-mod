# Omega Device Mod

A Rick and Morty-inspired mod for Minecraft Bedrock.

## Features

- Adds an Omega Device item inspired by Rick and Morty
- Clears entities and items within a 10-block radius
- Clears blocks in front of the player
- Eliminates players by putting them in spectator mode

## Requirements

- Minecraft Bedrock Edition 1.21.0 or later

## Installation

1. Download the mod files.
2. Place the `behavior_packs` and `resource_packs` folders in your Minecraft Bedrock Edition world's `behavior_packs` and `resource_packs` directories.
3. Enable the mod in the Minecraft Bedrock Edition settings.

## Usage

1. Craft or obtain the Omega Device item.
2. Right-click to use the Omega Device.

## Configuration

No additional configuration is required.
